# Deep Space Seed Twin

A 3D cellular digital twin of an *Arabidopsis thaliana* seed, from dry seed through imbibition, testa rupture and endosperm rupture to a ~5-day seedling, run under spaceflight hardware environments. It runs in the browser.

**Live tool:** https://dr-richard-barker.github.io/deepspace-seed-twin/
**Companion:** [DeepSpace Seed Stress Decoder](https://dr-richard-barker.github.io/deepspace-seed-stress-decoder/). The decoder reports *which* seed cell types carry the transcriptional signature of a spaceflight stressor. The twin asks *how* an environment reaches those cells — through water, gas exchange, hormones and growth — and what the seed and seedling then look like.

> Status: research software, version 0.1. The model is calibrated against published germination timing, and its spaceflight outputs are **hypotheses**. Every parameter carries an evidence tier (below). The manuscript is in preparation and has no DOI yet.

## What the model does

| Layer | What it represents | Main sources |
|---|---|---|
| Geometry | Procedural cellular seed: testa, single-layer endosperm and a bent-cotyledon embryo. Axis cells are indexed from the quiescent centre as in Bassel et al. 2014. **Schematic**: no open segmented embryo mesh exists. | Bassel 2014; Montenegro-Johnson 2015 (cell counts); Bou Daher 2018; Klasen 2025 (seed size) |
| Water | Imbibition to a plateau. Turgor above the wall-yield turgor scales with ψ − ψb (hydrotime). | Footitt 2019 |
| Gas | O₂, CO₂ and ethylene through the air boundary layer (Sh = 2 + 0.6 Re^½ Sc^⅓), water film, testa and endosperm, with a radial O₂ profile in the tissue and a headspace mass balance. Gas diffusivity ∝ 1/P. | Sander 2015; Tang 2014/2015; Stiti 2022; Verboven 2013 (proxy) |
| Hormones | Per-cell ABA–GA–Integrator network of Abley et al. 2021 (published equations and defaults), extended with a GA signal and GID1 graded from the radicle tip, cell–cell transport, CYP707A2 ABA catabolism, and ethylene from O₂-dependent ACC oxidase. | Abley 2021; Topham 2017; Bassel 2014; Okamoto 2006; Wang 2018; Dilley 2013 |
| Growth | Lockhart growth driven by wall stress, which scales with cell size. The testa and then the endosperm cap restrain the embryo until the cap weakens. | Bassel 2014; Linkies 2010 |
| Seedling | Root meristem division and elongation, gravitropism scaled by gravity, hypocotyl elongation without division, apical hook, ethylene triple response, cotyledon emergence and opening. | Beemster & Baskin 1998; Boyes 2001; Alimchandani 2026; Guzmán & Ecker 1990 |
| Radiation | Dose-rate scenarios (ISS measured, lunar surface, cruise, solar particle event) drive per-cell damage. Links from damage to hormones **default to zero**: no verified source quantifies them. | EDA via Hardware_OSDR_review; Zhang 2020; Simonsen 2020; Shavers 2024 |

### Hardware presets

`data/environments/*.json` are generated by `scripts/build_environments.py` from curated records, never typed by hand:

- **Hardware boundary conditions:** `Hardware_OSDR_review` (BRIC-PDFU, BRIC-LED, APH, EMCS, ISS cabin dose).
- **Dish geometry:** `LunarLeaf-CFD` (BRIC, CARA).
- **LEAF GBC1:** the `LEAF_GBC2_pot_model` geometry and pump scenario, plus a new lattice-Boltzmann run with the vendored LunarLeaf solver (`scripts/lbm_seed_runs.ts`).
- **Exploration-atmosphere set points:** `arabidopsis-exploration-atmosphere-tabpfn`.

Every field carries `{value, unit, source, tier}`.

## Evidence tiers

`data/params/parameter_ledger.csv` is the single source of truth. The model reads parameters only through it, and the build refuses a non-assumed row without a source.

| Tier | Meaning |
|---|---|
| measured | read from a cited measurement |
| standard | textbook constant or published model input |
| derived | computed from cited values (the arithmetic is in the row's note) |
| fitted | calibrated by `scripts/calibrate*.ts` against `data/calibration/targets*.json` |
| assumed | no source found — a modelling choice, shown as *assumed* in the tool |

References in `data/params/references.csv` are rebuilt from Crossref by `scripts/verify_references.py`. The source searches behind the ledger, including what could not be found, are in `data/params/research/`.

## Repository layout

```
app/                 Vite + React + Three.js tool (model in app/src/model, pure TypeScript)
data/params/         parameter ledger, verified references, research notes
data/environments/   hardware, atmosphere and radiation presets (generated)
data/calibration/    observed targets + fit results
data/decoder/        per-cell-type NES from deepspace-seed-stress-decoder (generated)
scripts/             builders, calibration, scenario export, LBM run (vendored LunarLeaf solver)
validation/          gates.ts — physics, conservation, mechanism, calibration, provenance gates
python/              independent kernel re-implementation + parity tests; figure script
results/tables/      every results table (generated by `npm run export`)
figures/             manuscript figures (generated by python/make_figures.py)
manuscript/          LaTeX manuscript (numbers injected from results/tables)
```

## Reproduce

```bash
npm ci
python3 scripts/build_ledger.py          # ledger → app/src/model/params.generated.json
python3 scripts/build_environments.py    # presets from sourced records
npm run gates                            # validation gates (also run in CI)
npm run export                           # scenario matrix → results/tables/
python3 python/make_figures.py           # figures/
npm run dev                              # the tool at http://localhost:5173
```

Calibration: `npm run calibrate` (germination), then `npm run calibrate:seedling`. Each writes a fit file; `python3 scripts/apply_fit.py <file>` copies the fitted values into the ledger.

Parity: `npm run kernels && python3 -m pytest python/tests`.

## Limitations

- The 3D geometry is schematic and built from cell counts, not a segmented embryo.
- Many parameters are still *assumed*; the Sources tab and `results/tables/ledger_tiers.csv` list them.
- The calibration fits several parameters to a handful of timing targets, so it is not identifiable. Agreement with a target shows the model *can* reproduce it, not that it is validated. Out-of-sample checks (population spread, water stress) are reported separately.
- The Topham 2017 and Bassel 2014 supplementary equations could not be retrieved, so the hormone core uses the fully published Abley 2021 model instead.
- Several sources are proxies: *Brassica napus* tissue diffusivities, *Lepidium* endosperm mechanics, and tomato and apple ACC oxidase kinetics.
